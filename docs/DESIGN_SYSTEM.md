# Design system

## Direction
Bold, expressive, hand-made energy, inspired by the Behance "Pizzeria Hands Font" project. Take the *attitude* (chunky type, warm contrast, playful details), not the artwork. Do not copy the original design, lettering or assets. Make it feel like a tool a 19-year-old seller is proud to screenshot.

## Tokens
| Token | Value |
|---|---|
| Background | `#0D0D0D` |
| Text | `#F5F0E8` |
| Accent (rust) | `#C94B2A` |
| Highlight (gold) | `#D4A017` |
| Headings | Space Grotesk |
| Labels / numbers | Space Mono |
| Body | Inter |

Light theme: invert surfaces, keep accents, re-check contrast.

## Principles
1. One primary action per screen.
2. Show the result fast: big preview, skeletons while generating.
3. Motion with purpose (under 250 ms), respect `prefers-reduced-motion`.
4. Mobile-first: sellers work on phones.
5. Accessibility: WCAG AA contrast, visible focus, keyboard navigation.
6. Copy: short, confident, no jargon.

## Key screens
Onboarding, Create (upload, pick, vibe), Results, Gallery, Collage, Plan and usage, Pricing.
